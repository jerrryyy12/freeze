# 01. 에셋 추출 가이드 (발로란트 → 언리얼)

> ⚠️ **개인용 전용.** 추출한 에셋을 공개 배포/업로드하면 Riot 저작권 및 이용약관 위반입니다.
> 본 프로젝트는 본인 PC에서 본인이 소장한 게임 파일을 개인적으로 감상하는 용도만 전제합니다.
> 추출 에셋은 절대 git에 커밋하지 마세요 (`.gitignore`에 `Content/Valorant/` 등록됨).

---

## 준비물

| 도구 | 용도 | 비고 |
|---|---|---|
| **ValorantPorting** | 무기 메시·스킨·애니메이션 UE 임포트 | 메인 도구 |
| **FModel** | 개별 에셋 탐색/추출 (특히 사운드·VFX 참조 확인) | 보조 |
| **최신 AES 키** | 발로란트 pak 복호화 | 패치마다 갱신됨 |
| **vgmstream (또는 wwiser)** | Wwise `.wem` → `.wav` 변환 | 사운드 관문 |
| **언리얼 엔진 4.27** | 프로젝트 엔진 | 발로란트 UE4 계열과 호환 좋음 |

> 발로란트 pak 경로(기본): `C:\Riot Games\VALORANT\live\ShooterGame\Content\Paks`

---

## 왜 UE 4.27 인가

발로란트는 UE4 계열 커스텀 빌드입니다. 스켈레톤·머티리얼·애니메이션 호환성 때문에
**UE 4.27**을 쓰는 게 가장 안전합니다. UE5로 열어도 되지만 스켈레탈/머티리얼에서
자잘한 재작업이 생길 수 있습니다.

---

## A. 무기 모델 + 스킨 (제일 쉬움 ★★☆)

1. ValorantPorting 실행 → 발로란트 설치 경로 지정 → 최신 AES 키 적용
2. 원하는 무기/스킨 검색 (예: Vandal > Reaver)
3. UE 임포트 대상: `Content/Valorant/Weapons/<무기>/` 로 정리
4. 결과물: `SkeletalMesh` + `Material Instance` + `Texture` 세트

**정리 규칙(권장):**
```
Content/Valorant/Weapons/Vandal/SK_Reaver_Vandal
Content/Valorant/Weapons/Vandal/Materials/MI_Reaver_*
Content/Valorant/Weapons/Vandal/Textures/T_Reaver_*
```

## B. 애니메이션 (★★☆)

- 발사/장전/집어들기/감상 애니메이션을 추출.
- **주의:** AnimSequence는 반드시 그 무기의 **스켈레톤**에 매칭돼야 합니다. 임포트 시
  스켈레톤이 안 맞으면 리타겟이 필요합니다.
- 재생은 **AnimMontage**로 감싸서 씁니다. AnimSequence를 우클릭 → **Create AnimMontage**.
  - 몽타주 이름 규칙: `AM_Vandal_Fire`, `AM_Vandal_Reload`, `AM_Vandal_Inspect`

## C. 사운드 (관문 ★★★)

발로란트 오디오는 대부분 **Wwise 뱅크(.bnk)** 안의 **.wem** 입니다. 그냥은 UE에서 못 읽습니다.

1. FModel로 해당 무기/스킨의 오디오 뱅크에서 `.wem` 추출
2. `vgmstream` 으로 `.wav` 변환:
   ```
   vgmstream-cli input.wem -o output.wav
   ```
   (여러 개면 배치 스크립트로 폴더 전체 변환)
3. UE에 `.wav` 임포트 → `SoundWave` 생성
4. 각 SoundWave 우클릭 → **Create > SoundCue** (볼륨/감쇠 조절용). Cue를 DataTable에 연결.
   - 이름 규칙: `S_Reaver_Fire`, `S_Reaver_Reload`, `S_Reaver_Kill`, `S_Reaver_Finisher`

> **팁:** 어떤 .wem이 어떤 사운드인지 이름만으로는 모릅니다. FModel 내장 오디오 플레이어로
> 하나씩 들어보며 매칭하거나, 커뮤니티가 정리한 ID 맵을 참고하세요.

## D. VFX (최대 난관 ★★★★★)

- 총구 화염·트레이서·**피니셔 이펙트**는 **Niagara** 시스템입니다.
- **ValorantPorting/FModel로 Niagara는 온전히 안 옵니다.** 참조·모듈이 깨져서 빈 채로 오거나 에러.
- 현실적 선택:
  1. **간소 재구성:** 텍스처(스파크/스모크)만 뽑아서 Niagara로 간단한 화염을 직접 제작
  2. **영상 대체:** 피니셔는 valorant-api.com 공식 프리뷰 영상으로 폴백 (DataTable의
     `FinisherPreviewVideo` 필드 사용) — `03_피니셔_구현.md` 참고
- 이 프로젝트의 블루프린트는 VFX가 `None`이어도 **크래시 없이 스킵**하도록 설계되어 있으니,
  VFX 없이 먼저 완성한 뒤 나중에 채워 넣어도 됩니다.

## E. 피니셔(마무리 모션) 에셋 (★★★★)

피니셔는 보통 다음으로 구성됩니다:
- 전용 **스켈레탈 메시** (용/로봇/카드 등) → 추출 가능
- 전용 **애니메이션** → 추출 가능 (스켈레톤 매칭 주의)
- **Niagara VFX** → 대부분 재현 어려움 (위 D 참고)
- **사운드** → Wwise 변환 (위 C 참고)

정리 규칙:
```
Content/Valorant/Finishers/SK_Reaver_Finisher
Content/Valorant/Finishers/AM_Reaver_Finisher
Content/Valorant/Finishers/S_Reaver_Finisher
Content/Valorant/Finishers/NS_Reaver_Finisher   (되는 경우만)
```
