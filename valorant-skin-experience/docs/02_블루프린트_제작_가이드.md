# 02. 블루프린트 제작 가이드 (노드 단위)

블루프린트는 바이너리라 git으로 못 드립니다. 대신 **에디터에서 그대로 조립할 수 있게**
필요한 BP 5개를 노드 흐름까지 적어둡니다. 순서대로 만드세요.

만들 블루프린트:
1. `BP_WeaponActor` — 무기 하나 (메시/애니/사운드/피니셔 전부 처리)
2. `BP_TargetDummy` — 맞으면 죽고 킬사운드/피니셔 트리거하는 더미
3. `BP_ExperiencePawn` — 1인칭 플레이어 (이동/시점/입력)
4. `PC_Experience` — 플레이어 컨트롤러 (마우스 커서/입력 모드)
5. `GM_SkinExperience` — 게임모드 (Pawn/PC 지정)

그리고 UI 위젯 `WBP_SkinHUD` (선택).

> 사전 준비: `Content/Data/README_DataTable.md` 대로 **`FSkinData` 구조체 + `DT_SkinTable`** 를
> 먼저 만들어 두세요. 아래 로직이 이걸 읽습니다.

## 1. BP_WeaponActor (핵심)

**부모 클래스:** Actor
**컴포넌트:**
- `SkeletalMeshComponent` (이름: `WeaponMeshComp`) — 루트
- `SceneComponent` (이름: `MuzzleSocket`) — 총구 위치. 실제로는 메시의 `Muzzle` 소켓을 쓸 것

**변수:**
| 변수 | 타입 | 용도 |
|---|---|---|
| CurrentSkin | FSkinData | 지금 로드된 스킨 데이터 |
| SkinRowName | Name | 지금 스킨의 행 이름 |

### 함수: `ApplySkin(FSkinData NewSkin)`
스킨 데이터를 받아 메시/머티리얼을 교체하는 함수.

```
[Set CurrentSkin = NewSkin]
   │
[Is Valid? NewSkin.WeaponMesh]  ──(Soft ref이면 Async Load Asset 후)──►
   │ true
[WeaponMeshComp → Set Skeletal Mesh (로드된 Mesh)]
   │
[Branch: NewSkin.MaterialOverride != None]
   │ true → [WeaponMeshComp → Set Material (0, 로드된 Material)]
   │
[PlaySound2D or SpawnSoundAttached(NewSkin.EquipSound)]  ← 집어들기 소리
```
> Soft Reference를 쓰면 `Async Load Asset` → 완료 콜백에서 Set. Hard Reference면 바로 Set.
> 처음엔 Hard로 단순하게 가고, 스킨 많아지면 Async로 바꾸세요.

### 이벤트: `Fire` (플레이어가 호출)
```
[Custom Event: Fire]
   │
[Play Anim Montage(WeaponMeshComp, CurrentSkin.FireAnim)]
   │
[Spawn Sound Attached(CurrentSkin.FireSound, WeaponMeshComp, "Muzzle")]
   │
[Branch: CurrentSkin.MuzzleFlashVFX != None]
   │ true → [Spawn System Attached (Niagara, WeaponMeshComp, "Muzzle")]
   │
[LineTraceByChannel]
   ├ Start = 카메라 위치   (플레이어에서 넘겨받거나 GetPlayerCameraManager)
   └ End   = Start + Forward * 10000
   │
[Branch: Hit && HitActor is BP_TargetDummy]
   │ true
[HitActor → Call "ReceiveHit(CurrentSkin, HitLocation)"]
```

### 함수: `PlayReload`, `PlayInspect`
```
[Play Anim Montage(WeaponMeshComp, CurrentSkin.ReloadAnim)] + [Spawn Sound(ReloadSound)]
[Play Anim Montage(WeaponMeshComp, CurrentSkin.InspectAnim)]
```

## 2. BP_TargetDummy

**부모:** Character (또는 Pawn) — 래그돌 쓰려면 Character가 편함
**컴포넌트:** 기본 CapsuleComponent + Mesh (마네킹/커스텀 더미 메시)

**변수:** `HP` (Float, 기본 100), `bDead` (Bool)

### 함수: `ReceiveHit(FSkinData Skin, Vector HitLocation)`
```
[Branch: bDead] ── true → return
   │ false
[HP = HP - 50]           ← 데미지 값은 취향껏
   │
[Branch: HP <= 0]
   │ true → [Call Die(Skin, HitLocation)]
   │ false → (히트 반응: 살짝 흔들기 / 히트마커 사운드 등, 선택)
```

### 함수: `Die(FSkinData Skin, Vector HitLocation)`
여기가 **킬 사운드 + 마무리 모션** 핵심.
```
[Set bDead = true]
   │
[Spawn Sound at Location(Skin.KillSound, HitLocation)]   ← 킬 사운드
   │
[Branch: Skin.FinisherMesh != None]           ← 피니셔 있는 스킨인가?
   │
   ├ true  → [Call PlayFinisher(Skin, GetActorLocation)]
   │
   └ false → [기본 사망 처리]
              [Mesh → Set Simulate Physics (true)]   ← 래그돌
              [Set Lifespan 5.0]  또는 [Set Timer → ResetDummy]
```

### 함수: `PlayFinisher(FSkinData Skin, Vector Loc)`  ★마무리 모션★
```
[더미 원본 메시 숨기기: Mesh → Set Visibility(false)]    ← 시체를 이펙트로 대체
   │
[Spawn Actor / Spawn Skeletal Mesh: Skin.FinisherMesh at Loc]
   │  (전용 액터 BP_FinisherActor를 만들어도 되고, 여기서 직접 SkeletalMeshComp 스폰)
   │
[Play Anim (Single Node) or Play Montage → Skin.FinisherAnim]
   │
[Spawn Sound at Location(Skin.FinisherSound, Loc)]
   │
[Branch: Skin.FinisherVFX != None]
   │ true → [Spawn System at Location(Skin.FinisherVFX, Loc)]
   │ false → (VFX 없음 - 스킵. 아쉬우면 03_피니셔_구현.md의 영상 폴백)
   │
[Set Timer 4~6초 → ResetDummy]     ← 피니셔 감상 후 리셋
```

### 함수: `ResetDummy`
```
[bDead=false] [HP=100] [Mesh Visibility=true] [Simulate Physics=false]
[스폰했던 피니셔 액터 Destroy] [원위치로 SetActorLocation]
```

## 3. BP_ExperiencePawn (1인칭 플레이어)

**부모:** Character
**컴포넌트:** CameraComponent (`FirstPersonCamera`) → Capsule에 부착.
- 무기는 카메라에 붙입니다: `BP_WeaponActor`를 스폰해서 `AttachToComponent(Camera)`.

**변수:** `CurrentWeapon` (BP_WeaponActor ref), `SkinRows` (Array of Name), `SkinIndex` (Int)

### BeginPlay
```
[Get Data Table Row Names(DT_SkinTable) → SkinRows]
[SkinIndex = 0]
[Call EquipSkinByIndex(0)]
```

### 함수: `EquipSkinByIndex(int Index)`
```
[Clamp/Wrap Index within SkinRows length]
[Get Data Table Row(DT_SkinTable, SkinRows[Index]) → RowData(FSkinData)]
   │
[Branch: CurrentWeapon 유효?]
   │ 없으면 → [Spawn Actor BP_WeaponActor → Attach to FirstPersonCamera]
   │
[CurrentWeapon → ApplySkin(RowData)]
[UI 갱신: WBP_SkinHUD → SetSkinName(RowData.DisplayName)]
```

### 입력 이벤트 (Input Action / Axis)
```
InputAction Fire      (Pressed) → CurrentWeapon → Fire
InputAction Reload    (Pressed) → CurrentWeapon → PlayReload
InputAction Inspect   (Pressed) → CurrentWeapon → PlayInspect
InputAction NextSkin  (Pressed) → SkinIndex++ → EquipSkinByIndex
InputAction PrevSkin  (Pressed) → SkinIndex-- → EquipSkinByIndex
InputAction ForceFinisher (Pressed) → (앞의 더미에 강제 Die 호출: 피니셔만 빨리 보고 싶을 때)
InputAction ResetDummy(Pressed) → 씬의 모든 BP_TargetDummy → ResetDummy
InputAxis MoveForward → Add Movement Input(Forward, Value)
InputAxis MoveRight   → Add Movement Input(Right, Value)
InputAxis Turn        → Add Controller Yaw Input
InputAxis LookUp      → Add Controller Pitch Input
```

> `ForceFinisher(X)` 키가 핵심 편의 기능: **적을 실제로 못 맞혀도 앞의 더미에 피니셔를 즉시
> 재생**시켜서 마무리 모션만 반복 감상할 수 있게 해줍니다. (스킨 미리보기의 목적에 딱)


## 5. GM_SkinExperience (게임모드)
```
Class Defaults:
  Default Pawn Class      = BP_ExperiencePawn
  Player Controller Class = PC_Experience
```

> `/Game/Blueprints/GM_SkinExperience` 로 지정돼 있으니, BP를 이 경로/이름으로 만드세요.

## 6. WBP_SkinHUD (선택 UI)
- 스킨 이름 텍스트, 조작키 안내(E/Q 스킨 변경, X 피니셔, R 장전, F 감상).
