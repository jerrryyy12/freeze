# 03. 마무리 모션(피니셔) 구현 심화

피니셔는 이 프로젝트에서 **가장 어렵지만 가장 보고 싶어하는** 부분입니다.
현실적으로 3가지 품질 레벨이 있고, 섞어 쓰는 걸 추천합니다.

---

## 레벨 A — 풀 3D 재현 (최고 품질 / 최고 난이도)

메시 + 애니메이션 + 사운드 + Niagara VFX 전부 UE에서 재생.

- 메시/애니/사운드는 추출로 가능 (`01_에셋_추출_가이드.md`).
- **Niagara VFX가 벽.** ValorantPorting/FModel이 Niagara를 온전히 못 가져옴.
  - 텍스처(스파크·연기·리본)만 추출해서 **직접 Niagara로 근사 재구성**.
  - 원본 프리뷰 영상을 보면서 색/타이밍/스폰 흉내.
- 작업량이 크므로 **정말 아끼는 스킨 1~2개만** 이 레벨로.

## 레벨 B — 인터랙티브(간소 VFX) (추천 기본값)

메시 + 애니 + 사운드는 재생, VFX는 되는 만큼 or 생략.

- `BP_TargetDummy.PlayFinisher`에서 `FinisherVFX == None`이면 스킵하도록 이미 설계됨.
- **이것만으로도 "쏴서 죽이면 그 스킨 전용 피니셔 오브젝트가 뜨고 사운드가 난다"** 는
  핵심 체험은 완성됩니다.

## 레벨 C — 영상 폴백 (최저 난이도 / 100% 정확)

3D 재현을 포기하고, **공식 프리뷰 영상**을 화면에 재생.

- `valorant-api.com`은 스킨 레벨별 **프리뷰 영상(mp4) URL**을 제공합니다.
- DataTable의 `FinisherPreviewVideo` 필드에 로컬 mp4 경로(또는 다운로드해 둔 파일)를 넣고,
  UE **Media Player + Media Texture**로 위젯에 재생.
- 인터랙티브는 아니지만 이펙트가 100% 정확하고 만들기 가장 쉬움.

### 영상 폴백 셋업 (UE)
1. `File Media Source` 생성 → mp4 경로 지정 (또는 런타임에 URL 지정)
2. `Media Player` 에셋 생성 → 대상 `Media Texture` 연결
3. `WBP_FinisherVideo` 위젯: Image 브러시에 Media Texture 물림
4. `Die`에서 피니셔 3D가 없으면 → 위젯 띄우고 `MediaPlayer → Open Source → Play`

> ⚠️ 영상도 개인 소장 범위에서만. 공개 재배포 금지.

---

## 추천 전략

```
아끼는 스킨 (리버/프라임 등)  → 레벨 A 또는 B (3D 인터랙티브)
나머지 대량                   → 레벨 C (영상으로 빠르게 훑기)
```

`DT_SkinTable` 한 곳에서 `FinisherMesh`가 있으면 3D 재생, 없고
`FinisherPreviewVideo`만 있으면 영상 재생 — 이렇게 분기하면 한 프로젝트에서 둘 다 굴러갑니다.

## Die 분기 최종 로직 (요약)
```
Die():
  KillSound 재생
  IF FinisherMesh != None:      → 레벨 A/B (3D 피니셔)
  ELSE IF FinisherPreviewVideo != "":  → 레벨 C (영상 위젯)
  ELSE:                          → 기본 래그돌 사망
```
