치지직 채팅 오버레이 CSS — 문제점과 해결 방법

OBS 브라우저 소스용 채팅 커스텀 CSS가 갑자기 안 먹을 때

1. 무슨 일이 일어났나

어느 날 갑자기 채팅 디자인(흰 말풍선 / 닉네임 숨김 / 글자색 등)이 전부 사라지고 치지직 기본 채팅으로 나옵니다. CSS 내용은 그대로인데 아무것도 적용되지 않습니다.

2. 원인 — 치지직이 클래스 이름을 바꿈

CSS는 live_chatting_message_wrapper 처럼 의미 있는 클래스 이름으로 채팅 요소를 찾습니다. 그런데 치지직이 사이트를 업데이트하면서 이름을 _item_f6gts_20 처럼 해시(임의 문자열)가 붙은 이름으로 바꿨습니다.

기존 (지금 안 먹는 이름)바뀐 실제 이름
live_overlay_item_item_f6gts_20
live_chatting_message_text_text_1s877_1
live_chatting_username_..._container_o04z9_2

기존 CSS는 [class^=live_...] (~로 시작) 으로 찾는데, 새 이름은 live_ 로 시작하지 않으니 하나도 못 잡아서 스타일이 통째로 죽은 것입니다.

3. 해결 방법

셀렉터를 "이름으로 시작" 에서 "이름 일부 포함" 으로 바꿉니다.

기존: [class^=live_overlay_item]

수정: [class*="_item_"]

용도수정 후 셀렉터
채팅 전체 컨테이너[class*="_chatting_"]
채팅 한 줄 (말풍선)[class*="_item_"]
메시지 글자[class*="_text_"]
닉네임 숨기기[class*="_wrapper_"] > [class*="_container_"]:first-child

4. 왜 이 방법이 더 안전한가

  • 해시(f6gts, o04z9)는 치지직이 업데이트할 때마다 또 바뀝니다.
  • [class*="_item_"] 처럼 의미 부분만 잡으면 해시가 바뀌어도 계속 작동합니다.
  • 닉네임은 이름이 아니라 위치(글자 바로 앞 요소)로 잡아서 더 잘 버팁니다.
다음에 또 깨지면? 브라우저에서 채팅 글자를 우클릭 → 검사(F12) 로 새 클래스 이름을 확인하고, 위 표의 셀렉터를 그 이름에 맞게 고치면 됩니다.
