# Freeze

마인크래프트 1.26.2 Forge 모드. 지정한 사각형 영역 밖으로 나가면 즉시 사망합니다.

## 빌드

```
./gradlew build
```

빌드된 `build/libs/freeze-1.0.0.jar` 파일을 클라이언트/서버의 `mods/` 폴더에 넣으세요.

## 명령어 (OP 필요)

| 명령어 | 설명 |
|--------|------|
| `/freeze pos1` | 현재 위치를 1번 모서리로 설정 |
| `/freeze pos2` | 현재 위치를 2번 모서리로 설정 |
| `/freeze on` | 영역 활성화 |
| `/freeze off` | 영역 비활성화 |
| `/freeze info` | 현재 설정 보기 |

## 동작

- 영역은 두 좌표 사이의 사각형(직육면체).
- 활성화된 상태에서 플레이어가 영역 밖으로 나가면 매 틱마다 즉시 사망 처리됩니다.
- 크리에이티브/스펙테이터 모드는 제외.
